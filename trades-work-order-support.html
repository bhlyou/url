Trades Work Order — Support

Offline job records, site photos, sign-off and PDF reports for tradespeople.

Get help

  • Email: hailubai@163.com
  • Please include your device model, iOS version and a short description of the issue.

Common topics

  • Write a work order: tap + on the Work Orders tab, then pick an existing customer or switch to New to add one.
  • Site photos: open a work order → Add Photos, or Camera. Tap a photo to mark it up; the original is always kept.
  • Signature: open a work order → Collect Signature. Signatures are optional — a job never needs one to be finished or shared.
  • PDF report: open a work order → Export, then choose a template.
  • Backup: Settings → Export All Work Orders (ZIP) packs every report, photo and signature into one file. Do this regularly: the data lives only on this device, so deleting the app deletes it too.

Requirements

  • iPhone or iPad running iOS 17 or later.
  • No account, no subscription and no network connection required.
