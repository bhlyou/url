A description of the file type, approximate size and steps to reproduce is usually enough. COMMON TOPICS Import a PDF In a PDF tool, choose From Files to import a local document or From Library to use a document already stored in the App. Documents shared from other apps arrive in the App's shared inbox. Scan a document Open Scan from the Home tab, capture the pages, adjust the scan if needed, and save the resulting PDF to the library. Convert and organize The Home tab provides image, Word, TXT and text to PDF conversion, plus merge, split, insert or delete pages, border trimming, scan correction and PDF to image tools. OCR Open the OCR tool and choose a PDF. Recognition results can be reviewed and exported without changing the original document. Sign, compress or protect Choose the corresponding tool, select a document, adjust the available options, and save or share the result. Export a file Use the iOS share sheet to decide where a copy goes, such as Files, iCloud Drive or Mail. The App does not choose a destination or upload the document for you. Storage and deletion Imported and generated documents live in the App's local library. Keep a separate copy of anything important. Deleting a document or the App cannot be undone. TROUBLESHOOTING - If a PDF is encrypted, unlock it with the correct password before using tools that require readable page content. - Very large or complex PDFs may take longer to process. Keep the App in the foreground until the operation finishes. - If an imported file does not appear, confirm that it is a supported document and try importing it again from Files.
