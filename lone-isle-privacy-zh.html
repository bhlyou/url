隐私政策 — 沧海孤岛

最后更新：2026-11-13

关于本应用

沧海孤岛（Lone Isle）是一款单机海岛即时战略游戏，不联网也能正常游玩。没有账号、没有登录、没有联机，也没有广告、订阅或内购。

我们收集什么数据

我们不收集你的姓名、邮箱、电话、地址、精确位置、通讯录、相册、麦克风或相机数据，也从不读取广告标识符（IDFA）。

应用使用 Google Analytics for Firebase 了解玩法情况，会上报：

  • 对局事件：开局与结束，附带模式（教程 / 战役 / 自由对战）、关卡、文明、地图、胜负与用时。
  • Firebase 自动附带的基础上下文：应用版本、设备型号、系统版本、语言，以及随机生成的应用实例 ID。

不上传你输入的任何文字、不上传存档，也不上传可识别个人身份的标识。这些数据不与你的身份关联，也不用于跨 App 或跨网站追踪。

系统权限

本应用不申请任何系统权限：不打开相机与麦克风，不读取相册与通讯录，也不请求位置、通知或 ATT 追踪授权。

我们如何使用数据

统计只用于判断哪些模式被玩、玩家在哪一关停下，从而改进游戏；不用于广告或用户画像，应用内也没有广告 SDK。

第三方 SDK

唯一的第三方 SDK 是 Google Analytics for Firebase（FirebaseAnalyticsWithoutAdIdSupport，不读取广告标识符）。Google 作为受托方按 Google 隐私权政策与 Firebase 隐私与安全条款处理这些数据。应用内没有其他分析、广告或追踪 SDK。

数据存储

  • 对局存档以 JSON 文件写在应用自己的 Application Support 目录里，仅存于本机。
  • 少量偏好设置（例如教程是否已完成）使用 UserDefaults 保存。
  • 统计事件会发送到 Google 服务器，按我们 Firebase 项目的保留期保存。
  • 不使用 iCloud 同步。
  • 不导出存档到任何外部服务。
  • 删除应用即删除本机文件。

儿童隐私

本应用不针对 13 岁以下儿童，不收集任何年龄信息。

您的权利

你可以来信查询与你应用实例相关的统计数据、要求删除，或反对统计处理。存档从不离开设备，因此我们这边没有可导出或删除的存档。
