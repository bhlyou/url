Frequently Asked Questions

Does the app need internet access?
No. Reading, scanning, page correction, OCR, annotation, merging, splitting, compression and encryption all run on the device. Everything works in Airplane Mode and no file is uploaded.

Do I need an account?
No. There is no sign-in screen, no account, and no analytics or advertising SDK.

Can it open a PDF of several hundred pages?
Yes. Pages are rendered one at a time as you scroll, so the memory used does not grow with the page count. Home → Large-file check-up renders an entire document page by page and draws the memory curve, so you can verify this on your own device.

Where are my files stored?
Inside the app's own sandbox container on your device. Nothing is exposed in the system Files app. Deleted files stay recoverable in the 7-day bin before being purged.

Why does the app ask for Camera / Face ID / Local Network?
Camera is only for photographing paper into a scanned PDF. Face ID is only for the optional app lock. Local network is only used when you deliberately send a file to your own computer on the same Wi-Fi. Declining any of them leaves the rest of the app fully usable.

Why is a page kept as photographed instead of cropped?
When edge detection is not confident, the page is kept exactly as shot rather than risk cropping text away.
